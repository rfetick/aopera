Simulation¶

aopera.simulation.simulation(nx, samp, *args, nu_max=None, verbose=False, split_fit_temp=True, nb_iter_og=None, return_cpu=True, ignore=[], keep_cubes=True, cube_bins=None)¶

Run a full AO simulation from a given set of objects representing the AO system and the turbulence. This might be the main function of AOPERA.

Parameters:

  • nx (int) – Number of pixels for output arrays.

  • samp (float) – Sampling of the PSF at the WFS wavelength.

  • *args – Must include a Pupil, Atmosphere, WFS, RTC, SourceWFS, SourceScience.

  • nu_max (float, default=None) – Maximal temporal frequency.

  • verbose (bool, default=False) – Activate verbose mode.

  • split_fit_temp (bool, default=False) – Split fitting and temporal error for the returned PSD dictionary.

  • nb_iter_og (int, default=None) – Number of iterations for OG computation.

  • return_cpu (bool, default=True) – Return result as CPU or GPU arrays.

  • ignore (list, default=[]) – List of error terms to ignore.

  • keep_cubes (bool, default=True) – Keep the spatiotemporal and aliasing PSD cubes (psd_cube and frequency_cube) in the result. They are needed to feed another AO stage, but can be huge (memory grows with the number of layers). Set to False for the last stage: the PSD is then accumulated without storing the cubes.

  • cube_bins (int, default=None) – If set, the spatiotemporal and aliasing PSD cubes are gathered in cube_bins temporal frequency bins (log-spaced), instead of one entry per layer and per aliased frequency. The PSD of each bin is exact, its frequency is the PSD-weighted mean frequency. For an input result (second stage), all the input cubes are also gathered in cube_bins bins. This bounds the memory whatever the number of layers, at the cost of a small approximation on the temporal filtering of the next stage. Typical value: 100 to 200.

Returns:

result – Container of the results

Return type:

SimulationResult

aopera.ffwfs.sensitivity_ramp(sensi, samp, radius)¶

Low-order correction of a (centered) sensitivity map: inside the radius radius [lambda/D], the map is replaced, along each direction, by a linear ramp from 0 at the null frequency to its value on the circle of radius radius (slope-sensor regime of the modulated pyramid).

\[S_{new}(f) = S(f_r) * |f| / radius, f_r = radius * f/|f|\]

Outside the radius the map is unchanged.

class aopera.coronagraph.Coronagraph(tel, nx, samp, exact_radius=10.0, batch=16)¶

Long-exposure image through any linear coronagraph on the PSF grid of AOPERA.

A coronagraph is defined by propagate(field): pupil field (nx, nx) or (batch, nx, nx), with the pupil sampled as tel.pupil(nx, samp) -> field on the detector, unshifted FFT index space, with the normalization of fft2 (without coronagraph, propagate = fft2).

Parameters:

  • tel (Pupil)

  • nx (int, size of the arrays (same as the PSD / PSF).)

  • samp (float, sampling of the PSF (pixels per lambda/D), same as the PSD.)

  • exact_radius (float [lambda/D], the coronagraphic images of the sources closer to the axis are) – computed exactly (one propagation per pixel); beyond, shift-invariant response.

  • batch (int, number of tilted plane waves propagated together.)

raw_contrast(psd, min_throughput=0.01, return_cpu=True)¶

Raw contrast: long-exposure coronagraphic image divided by the peak of the image of an off-axis point source at the same position, i.e. by

(peak of the long-exposure AO PSF without coronagraph) x (peak throughput at x),

both computed from the same residual phase PSD. The peak of the AO PSF is the diffraction peak x Strehl (normalization of the E2E / COMPASS curves, which do not include the throughput). Close to the axis the throughput goes to 0: the raw contrast is set to NaN where the peak throughput is below min_throughput.

Parameters:

  • psd ((nx, nx) array, phase PSD [rad² m²] on the AOPERA grid (frequency step 1/(samp*D)),) – at the wavelength of the image.

  • min_throughput (float, minimum peak throughput (default 1 %).)

Returns:

raw_contrast

aopera.control.bandwidth(ki, nb_frame_delay, ao_freq, db=0)¶

Compute the AO bandwidth for an integrator control law.

\[BW_{db} = \frac{F}{2\pi}\frac{k_i}{\sqrt{k_i(2N_d+1)+10^{-db}-1}}\]
Parameters:

  • ki (float) – Gain of the integrator law

  • nb_frame_delay (float) – Number of frame delay (exposure frame excluded)

  • ao_freq (float) – Loop frequency [Hz]

  • db (float, default=0) – The cutoff in decibel.

aopera.control.bandwidth_noise(ki, nb_frame_delay, ao_freq, db=-4.5)¶

Compute the noise bandwidth for an integrator control law.

Parameters:

  • ki (float) – Gain of the integrator law

  • nb_frame_delay (float) – Number of frame delay (exposure frame excluded)

  • ao_freq (float) – Loop frequency [Hz]

  • db (float, default=-4.5) – The cutoff in decibel.

Note

A bandwidth at -4.5 dB is chosen so we get the equality between the integration of |NTF|² (in the discrete domain) and the bandwidth_noise expression.

\[BW_{noise} \simeq \int_0^{+\infty}|NTF(f)|^2 df\]

So it has to be multiplied by 2 to account for both positive and negative frequencies.

aopera.control.lqg_controller(fx, fy, phase_psd, noise_psd, cn2dh_ratio, wind_speed, wind_direction, ao_freq, delta_wind_speed=0.1, diameter=inf, verbose=False)¶

Compute LQG controller for each spatial frequency (fx,fy). Only valid for two frames delay (1 for WFS integration, 1 for pixel transfer and RTC computation).

Parameters:

  • fy (list of floats) – Spatial frequencies [1/m] along Y.

  • wind_direction (list of floats) – Wind direction [deg] of turbulence layers.

  • ao_freq (float) – AO loop frequency [Hz].

  • Keywords

  • --------

  • diameter (float) – Telescope diameter [m].

  • verbose (bool) – Print iterations while you drink a cup of tea.

Returns:
