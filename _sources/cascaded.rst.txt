Cascaded AO
===========

A second AO stage does not see the atmosphere: it sees what the first stage left behind.
In AOPERA, the result of a first ``simulation`` is simply given as input to a second one.
This tutorial follows ``example/AO_cascaded_simulation.py``, and the code shown here is read from that script.
You should have done :doc:`tutorial` first.

.. raw:: html

   <p>The same path is drawn on the <a href="flow.html#second-stage">Second Stage AO tab of the code flow</a>.</p>
