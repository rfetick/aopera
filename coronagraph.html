Coronagraphic image¶

From the residual PSD of a simulation, AOPERA computes the long-exposure image behind a perfect coronagraph, and its contrast curve. This tutorial follows example/coronagraph_simulation.py, and the code shown here is read from that script. You should have done Tutorial first.

Parameters¶

CORO_ORDER is the order of the perfect coronagraph: 2 removes the piston from the pupil field, 4 also removes tip and tilt, and so on.

file_instru = 'saxo.ini'
CORO_ORDER = 2
nx = 512
samp = 2
IGNORE = ['jitter','ncpa','chromatic','refraction']
CUBE_BINS = 100

Objects of the simulation¶

These are the same objects as in the first tutorial. This script uses a VLTPupil, which includes the spiders.

# Telescope and atmosphere
src_sci = SourceScience.from_file(file_instru)
atm = Atmosphere.from_file(file_instru )

# AO parameters
src_wfs = SourceWFS.from_file(file_instru )
src_sci_wfs_2 = SourceScience.from_file(file_instru )
tel = VLTPupil(read_config_file(file_instru , 'pupil'), t_spiders=0.00625, angle_spiders=50.5)
rtc = RTC.from_file(file_instru )
wfs = SHWFS.from_file(file_instru)

AO simulation¶

The simulation itself does not change: the coronagraph only uses its output PSD.

result_first_stage =  simulation(nx, samp, tel, atm, rtc, wfs, src_sci, src_wfs, verbose=True, ignore=IGNORE, cube_bins=CUBE_BINS)
psd, var, param = result_first_stage.psd, result_first_stage.var, result_first_stage.param
psd_total = sum([psd[k] for k in psd.keys()])

Coronagraphic image¶

The output PSD is given at the wavelength of the WFS, so it is first scaled to the science wavelength. The sampling grows with the wavelength: samp_sci is the sampling at the science wavelength, and the coronagraph must be built with it.

wvl_wfs_sci = src_wfs.wvl / src_sci.wvl 
samp_sci = samp / wvl_wfs_sci
psd_total_sci = psd_wvl_scaling(psd_total, wvl_wfs_sci)
coro = PerfectCoronagraph(tel, nx, samp_sci, order=CORO_ORDER)
img = coro.psf(psd_total_sci)
sep, contrast = coro.contrast_curve(img)

coro.psf returns the image in units of a unit-energy PSF. coro.contrast_curve normalizes it by the peak of the diffraction PSF without coronagraph, and returns its azimuthal average against the separation in λ/D. To normalize by the peak of an off-axis source through the coronagraph instead, use coro.raw_contrast with the PSD.

Plot¶

coro.normalized_intensities gives the 2D map with the same normalization as the contrast curve.

hfov = 30 # half field of view of the plots [lambda/D]
contrast_map = coro.normalized_intensities(img)
ext = nx / (2*samp_sci)
norm = LogNorm(vmin=1e-7, vmax=1e-2)

plt.figure(1, figsize=(10,4.2))
plt.clf()

plt.subplot(121)
plt.imshow(contrast_map, extent=(-ext,ext)*2, origin='lower', norm=norm)
plt.colorbar(label='Contrast')
plt.xlim(-hfov, hfov)
plt.ylim(-hfov, hfov)
plt.xlabel(r'Position [$\lambda/D$]')
plt.ylabel(r'Position [$\lambda/D$]')
plt.title('Coronagraphic image')

plt.subplot(122)
plt.semilogy(sep, contrast, lw=2)
plt.xlim(0, hfov)
plt.ylim(norm.vmin, norm.vmax)
plt.grid(which='both', alpha=0.3)
plt.xlabel(r'Separation [$\lambda/D$]')
plt.ylabel('Azimuthal average of the contrast')
plt.title('Contrast curve')

plt.tight_layout()
plt.show()

Result¶

The dark area is the region corrected by the deformable mirror.
